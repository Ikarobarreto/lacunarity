# lacunarity: lacunarity and generalized lacunarity for binary time series

Estimators of the gliding-box lacunarity index and of the generalized
(multifractal-like) lacunarity for one-dimensional binary series. See
the package vignette,
[`vignette("lacunarity")`](https://ikarobarreto.github.io/lacunarity/articles/lacunarity.md),
for the underlying theory and worked examples.

## Main functions

- [`lac`](https://ikarobarreto.github.io/lacunarity/reference/lac.md):

  ordinary lacunarity index \\\Lambda(s)\\ and its scaling exponent.

- [`genlac`](https://ikarobarreto.github.io/lacunarity/reference/genlac.md):

  generalized lacunarity \\\Lambda_q(s)\\ and the spectrum of exponents
  \\\gamma(q)\\.
