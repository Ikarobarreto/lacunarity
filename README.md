# lacunarity

<!-- badges: start -->
<!-- badges: end -->

The goal of lacunarity is to estimate lacunarity and generalized
lacunarity for unidimensional time series.

## Methodology

## Installation

You can install the released version of lacunarity from
[CRAN](https://CRAN.R-project.org) with:

``` r
install.packages("lacunarity")
```

And the development version from [GitHub](https://github.com/) with:

``` r
# install.packages("devtools")
devtools::install_github("Ikarobarreto/lacunarity")
```

## Example

We are going to simulate a two sets of 1200 bernoulli random variables
of 0’s an 1’s with probabilities of success of 80% and 50% calculating
lacunairty of them using lac function:

``` r
library(lacunarity)
x<-rbinom(n=1200,size=1,prob=.8)
y<-rbinom(n=1200,size=1,prob=.5)

lac(x)
#> $y
#> [1] 0.01069921
#> 
#> $Ds
#> [1] 1.121311 1.060297 1.029682 1.014002 1.006606
#> 
#> $s
#>      [,1]
#> [1,]    2
#> [2,]    4
#> [3,]    8
#> [4,]   16
#> [5,]   32
lac(y)
#> $y
#> [1] 0.1332097
#> 
#> $Ds
#> [1] 1.536302 1.281904 1.129982
#> 
#> $s
#>      [,1]
#> [1,]    2
#> [2,]    4
#> [3,]    8
## basic example code
```

The results showed

*Δ*(*s*)

*s*
. We can observe that
*s*
parameter has less possible values for y than x and we could infer is
because of lower probability of success. However, this is not true,
because some coded time series could have 50% of 0’s and has different
lacunatiries. For example, lets simulate a 25 sequences of 0’s and 1’s
sub-sequences of size 8 and 16 each:

``` r
library(lacunarity)
z<-c(rep(c(rep(1,8),rep(0,8)),25),rep(c(rep(1,16),rep(0,16)),25))
table(z)
#> z
#>   0   1 
#> 600 600
lac(x)
#> $y
#> [1] 0.01069921
#> 
#> $Ds
#> [1] 1.121311 1.060297 1.029682 1.014002 1.006606
#> 
#> $s
#>      [,1]
#> [1,]    2
#> [2,]    4
#> [3,]    8
#> [4,]   16
#> [5,]   32
lac(z)
#> $y
#> [1] 0.1908516
#> 
#> $Ds
#> [1] 1.917431 1.793233 1.564334 1.223616
#> 
#> $s
#>      [,1]
#> [1,]    2
#> [2,]    4
#> [3,]    8
#> [4,]   16
## basic example code
```

As we can see, both series x and z has around 50% probability of 0’s and
1’s but different lacunarities.
